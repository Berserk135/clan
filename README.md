# Полудень — сканер аукциона и панель торговца

Одна программа вместо двух: бывший веб-монитор аукциона (`server.ps1`) и StalZone Desk
теперь работают в одном процессе, на одном порту, с одним ключом API и одним учётом квоты.
Страница открывается в браузере. Разделы:

- **Рынок** (главная) — оборот по категориям за сутки, топ по обороту, самые дорогие
  и последние продажи. Считается по продажам, которые программа скачала сама.
- **Предметы** — вся база игры: поиск, категории, карточки с главными характеристиками.
  Страница предмета: обзор рынка (минимум сейчас, обычная цена, разброс, продажи в день,
  оборот, ликвидность и риск), все лоты с «выгодой», история цен, характеристики,
  получение и крафт, описание. Фильтр по качеству и заточке.
- **Слежение** — кнопка «Следить за ценой» на странице предмета: когда появится лот не дороже
  вашей цены, программа покажет уведомление (колокольчик, рабочий стол) и напишет в Telegram,
  если бот настроен в «Настройках».
- **Журнал сделок** — проданные позиции портфеля с прибылью после комиссии.

Инструменты:

1. **Выгодные лоты** — лоты, которые можно выкупить и перевыставить дороже. Сканер без остановки
   обходит аукцион; свежевыставленные выгодные лоты появляются за секунды. В окне с графиком
   цен есть кнопки «Страница предмета» и «В портфель».
2. **Тренды** — все предметы в том же виде, что лоты на аукционе: что дорожает и что дешевеет
   за 6 часов, сутки, 3 дня или неделю, отдельно по качеству и заточке, с мини-графиком за 14 дней
   и историей цен по клику. Сверху — в какие часы суток рынок дешевле и дороже обычного.
3. **Портфель** — сколько вложено, сколько это стоит сейчас и когда выгоднее выставлять.
   У артефактов указывается качество и заточка — оценка идёт по продажам именно такого качества.

Число свежих выгодных лотов видно на вкладке «Выгодные лоты» и в заголовке окна, даже когда открыта
другая вкладка; звуковое оповещение тоже продолжает работать.

## Запуск

Двойной щелчок по **`Запуск.cmd`**. При первом запуске он сам установит библиотеки
из `requirements.txt` (нужен Python 3.10+). Браузер откроется на `http://localhost:8765/`.
Остановка — Ctrl+C или закрыть окно.

Из консоли то же самое:

```bash
python -m szdesk
```

Флаги: `--no-browser`, `--no-sniper` (без сканера аукциона), `--no-collector` (без сбора истории).

## Настройки — `config.json`

Один файл на всё. Его же читает `sc-deals.ps1`, поэтому общие ключи лежат в корне:

| Ключ | Что это |
|---|---|
| `client_id`, `client_secret` | ключи StalZone API |
| `region` | регион аукциона |
| `commission_percent` | комиссия аукциона, от неё зависят все расчёты прибыли |
| `port` | порт страницы |
| `web_*` | сканер аукциона: число воркеров, сколько страниц лотов смотреть и т.д. |
| `web_categories` | какие категории отслеживать; меняется на странице кнопкой «📋 Предметы» |
| `desk` | панель: ликвидность, темп фонового сборщика, путь к базе |

## Два режима сканера и кэш истории

- Пока открыта вкладка **«Выгодные лоты»**, сканер ищет выгодные лоты.
- На остальных вкладках (и когда страница закрыта) он лоты не ищет, а обновляет **кэш истории
  продаж и лотов**: сначала то, за чем вы следите, ваш портфель и недавно открытые предметы
  (не старше получаса), потом ходовые (раз в 2 часа) и остальное (раз в 12 часов).
  Слежение за ценой работает в обоих режимах.
- История за 30 дней и лоты хранятся в базе программы и копируются в кэш браузера,
  поэтому графики и страница предмета открываются сразу; свежие данные догружаются следом,
  подпись «данные обновлены …» показывает их возраст.
- Текущий режим виден в верхней панели рядом с квотой.

## Квота API

Квота одна на ключ — около 400 запросов в минуту. Раньше две программы делили её вслепую,
теперь запросы идут в порядке важности:

1. то, что вы ждёте на странице (график, лоты на странице предмета);
2. сканер аукциона — останавливается, когда в окне остаётся 30 запросов;
3. фоновый сборщик истории — уступает остальным, когда остаётся 60.

Не запускайте несколько копий программы: они будут отнимать квоту друг у друга.

## Как считается выгода

**Аукцион.** Лот выгоден, если следующий такой же лот (то же качество, заточка, свойства модуля)
дороже нашей покупки даже после комиссии. Показывается только самый дешёвый лот своего качества.
Рыночная цена по продажам за сутки (при нехватке — за 3 дня) — для справки и фильтров.

**Тренды.** Медиана цены за штуку, взвешенная количеством, за последний период против предыдущего.
Скачки, где сменился размер лотов (вместо пачек стали продавать поштучно втридорога), помечаются
и по умолчанию скрыты. Данные копятся сами: сканер аукциона сохраняет историю продаж, которую и так
скачивает, а сборщик разово догружает по странице продаж из прошлого (полдня, 1,5, 3 … 12 дней назад).
В базе хранится выборка — не больше 6 продаж на предмет, качество и час, — и только за 21 день.

Первые полчаса после самого первого запуска панель наполняется: сборщик обходит
торгуемые предметы и копит историю продаж. Часовой профиль уточняется каждый день.

## Что важно знать

- **API только на чтение.** Купить или выставить лот через него нельзя. Программа считает,
  вы нажимаете.
- **Предметы с характеристиками** (артефакты, изношенное снаряжение) в трендах
  считаются отдельно по качеству и заточке: у них цена зависит от этого в разы.

## Устройство

| Файл | Что делает |
|---|---|
| `szdesk/sniper.py` | сканер аукциона (перенесён из `server.ps1`) |
| `szdesk/market.py` | рынок за сутки, каталог, страница предмета, слежение, настройки |
| `szdesk/notify.py` | проверка слежения и сообщения в Telegram |
| `szcore/itemdb.py` | карточки предметов из базы игры (кэш в `data/cache/items_ru`) |
| `szdesk/server.py` | HTTP API и страницы |
| `szdesk/collector.py` | фоновый сбор истории продаж |
| `szdesk/recipes.py` | бартер и крафт — вкладка «Получение и крафт» у предмета |
| `szdesk/trends.py` | часовой профиль, движение цен, совет по продаже |
| `szdesk/static/` | страницы: `index.html` (общая), `auction.html` (аукцион) |
| `szcore/` | клиент API с учётом квоты, каталог предметов, настройки, база SQLite |
| `market-cache.json` | кэш сканера: после перезапуска цены видны сразу |
| `module-names.json` | названия свойств оружейных модулей (`update-module-names.ps1`) |
| `data/` | база продаж, портфель и кэш базы предметов |

Отдельно остались `sc-deals.ps1` (слежение в консоли и Telegram) и служебный
`tools_status_probe.py`. Прежние версии обеих программ лежат
в папке `_старая версия` — её можно удалить, когда убедитесь, что всё работает.
